## Integration surface (what actually exists)

- The VISION server passes case data from the Quantum Workstations to the hospital EHR over HL7 v2 interfaces, using an embedded Mirth Connect interface engine supplied by MIRTH Inc.
- Quantum Informatics deploys on customer-supplied infrastructure: Windows Server + SQL Server, three databases per environment (MIRTHDB for interfaces, VISION for archive, VISION_LIVE for live), a customer-supplied SSL certificate and customer DNS aliases (e.g. QI.yourdomain.com).
- Third-party device connectivity (patient monitors, cerebral oximetry, other OR devices) is delivered through optional device-driver software on the Quantum Workstation, not through a published API.
- An anesthesia interface suite has been integrated with MEDITECH HIS.
